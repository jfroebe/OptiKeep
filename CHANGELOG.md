# Changelog

## 0.1.0 development preview

- Add a PostgreSQL/SQLite3 schema and transaction adapter.
- Add bounded discovery, explicit trusted-cache reuse and durable run/task records.
- Add current task leases, heartbeats and idempotent result acknowledgements.
- Add read-only internal image hashes/measurements and FFprobe video metadata.
- Add indexed SHA-256 candidate review, authenticated API and initial web interface.
- Add pinned Czkawka binary packaging and Linux disposable-backend test contracts.
- Keep the global safety barrier closed until complete detection, keeper selection
  and filesystem recovery implementations are qualified.
